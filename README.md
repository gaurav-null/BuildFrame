## Why
 - A common complaint that many overFrame users have are the voting system and the build moderation and other project cant use the info present in overframe.

## How is this better?
 - We are going to fetch the update from the warframe API and list them in the update list. This update list will heavy affect how vote decay starts! (The vote will start decreasing as soon as a new update drops and exponentially with each consecutive update *unless updated*)
 - A Public API, so that other project can use the community builds.
